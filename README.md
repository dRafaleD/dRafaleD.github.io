# Eren Erdoğan — Kişisel tanıtım sitesi

GitHub profilimdeki siyah, yeşil ve terminal temasından esinlenen Türkçe kişisel site. HTML, CSS ve JavaScript ile hazırlandı; derleme ya da paket kurulumu gerekmez.

## Bilgisayarında aç

`index.html` dosyasına çift tıkla. Tüm sayfa ve bağlantılar yerel olarak çalışır. Google Fonts için internet bağlantısı gerekir; çevrimdışı kullanımda sistem yazı tipleri kullanılır.

## GitHub Pages'e yükle

1. GitHub'da bu site için bir depo oluştur (örneğin `kisisel-site`).
2. `index.html`, `styles.css`, `script.js`, `favicon.svg` ve `.nojekyll` dosyaları ile `assets` klasörünü deponun köküne yükle.
3. Depoda **Settings → Pages → Build and deployment → Source → Deploy from a branch** seç.
4. Dal olarak `main`, klasör olarak **/ (root)** seçip **Save** düğmesine bas.
5. Yayın işlemi tamamlandığında Pages ekranındaki **Visit site** bağlantısından aç.

`kisisel-site` adlı bir depo için adres `https://dRafaleD.github.io/kisisel-site/` olur. Doğrudan `https://dRafaleD.github.io/` adresini kullanmak istersen deponun adı `dRafaleD.github.io` olmalıdır. Bu adresler depo oluşturulup Pages yayını tamamlandıktan sonra kullanılabilir.

## Düzenleme

- Kişisel metinler, proje ve sosyal bağlantılar: `index.html`
- Renkler, yazı tipleri ve mobil görünüm: `styles.css` (`:root` renk değişkenleri)
- Menüde bölüm vurgusu ve otomatik yıl: `script.js`

Tanıtım terminali ve proje görselleri ilgili GitHub README dosyalarındaki özgün varlıklardır; `assets/` altında yerel olarak saklanır. Terminaldeki istatistikler görselin oluşturulduğu anı gösterir. REPORA görseli, README dosyasındaki terminal ekran görüntüsüdür. Hareketi azaltmayı tercih edenlerde GIF yerine sabit kare gösterilir. Form veya sunucu gerektiren özellik bulunmaz. Bağlantılar doğrudan GitHub ve LinkedIn profillerine gider.

## Arayüz özellikleri

Projeler Analiz, Gizlilik ve Kod güvenliği alanlarına göre filtrelenebilir. Tanıtım terminalindeki düğme, sitedeki animasyonları durdurur veya yeniden başlatır. İşletim sisteminin hareketi azalt tercihi otomatik olarak uygulanır. JavaScript kapalıyken tüm projeler ve gezinme bağlantıları kullanılabilir.
